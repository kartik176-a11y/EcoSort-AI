# EcoSort AI — Smart Waste Segregation & Disposal Assistant

## Project focus

This application supports household waste classification and disposal guidance in a way that is transparent, grounded in retrieved evidence, and suitable for a quick local prototype demonstration.

## Local knowledge sources

The project includes a small local knowledge database with guidance themes inspired by:

- GVMC / Green City Action Plan themes
- Swachh Bharat Mission waste-management guidance
- Municipal solid-waste segregation references
- General hazardous and e-waste handling guidance

## Notes

The local knowledge base is a lightweight demo fallback. It is not a substitute for official municipal instructions, especially for hazardous or e-waste items.
