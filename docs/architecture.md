# EcoSort AI architecture

## Overview

EcoSort AI uses a simple, transparent three-stage workflow:

1. Classification Agent
2. Retrieval Agent
3. Advisory Agent

This keeps the system easy to understand and suitable for demonstration in under 3 minutes.

## Classification

The classifier uses deterministic keyword rules for common waste items. It maps item names to categories such as:

- Wet/Biodegradable
- Dry/Recyclable
- E-waste
- Hazardous/Special waste
- Other/Uncertain

## Retrieval

The retrieval layer reads local documents and uses a lightweight in-memory similarity search over document chunks. This provides source-grounded reference material for each item.

## Advisory generation

The final response is generated by a Granite-compatible adapter when configured, otherwise by a clearly labelled demo fallback. The final answer must be grounded in the retrieved evidence and can include a warning when evidence is limited.

## Responsible AI notes

The project intentionally avoids claiming official municipal authority. It clearly separates general advice from local requirements and communicates uncertainty when needed.
